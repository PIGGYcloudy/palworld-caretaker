# Discord Bot Setup

This guide is intentionally a placeholder for the project maintainer's manual,
screenshot-based setup instructions.

The final guide should cover:

1. Creating a Discord application and bot.
2. Enabling the required application command scopes and channel permissions.
3. Finding the guild, channel, allowed-role, and administrator-role IDs.
4. Running `sudo /usr/local/sbin/palworld-discord-configure`.
5. Testing `/pal status`, `/pal start`, and administrator-only commands.
6. Revoking and replacing a leaked token.

Never paste a bot token into an issue, commit, screenshot, or chat message.
